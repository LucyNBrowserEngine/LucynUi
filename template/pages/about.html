LucyN UI

Why this exists

LucyN UI is part of the LucyN engine family. It was mainly made because I didn't like Electron being big, and also hated how hard Qt made UI to build.

So I asked myself: is it possible to build a desktop app in plain, simple HTML, CSS and JS? Turned out it is. I came across the likes of Tauri and Electron, but learning they were 200+ MB for a start, I stopped there.

Then I found a webview library — the infamous single webview.h file. I thought about writing a Bun wrapper for it myself, then discovered webview-bun, which had already written that exact wrapper.

So what did I do? Like a noble citizen of open source: forked it, merged it in. And well, here we are — LucyN UI.
