LucyN UI

Docs

Your app is just files plus a dependency on lucynui:

app.ts — entry point, calls createApp()
index.html — your UI
style.css
app.js
lucyn.config.ts — title / size / port

Commands

bun run app.ts — start the app
lucyn dev — dev server + window, hot reload on html/css/js changes
lucyn build — single binary in ./dist

Config

lucyn.config.ts in your project root, every field optional: title, width, height, port, dev.

API Reference

I mean — do you know HTML? Yes. Do you know CSS? Yes. Do you know JS? Yes. Then what the hell are you doing here, just go edit the template.

From <createdappfolder>/app.ts, you've got two ways to run it:

bun run app.ts or lucynui dev — start the app
bun run build or lucynui build — ship a binary

That's the whole API. You already know the rest.
